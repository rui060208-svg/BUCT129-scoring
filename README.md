# 一二·九合唱比赛计分台

面向北京化工大学一二·九合唱比赛的共享计分台。包含评委录分、特色奖票选、获奖展示和 CSV 导出。所有录分员连接同一台主机，成绩、票数、备份和登录记录由主机保存。

## 本机启动

需要 Python 3.10 或更新版本。macOS 和 Linux 均可运行服务端。使用以下命令初始化管理员密码并启动：

```bash
python3 server.py set-admin --data-dir "$HOME/choir129-data"
python3 server.py serve --data-dir "$HOME/choir129-data" --port 8789
```

1. 在主机浏览器打开 [本机计分台](http://127.0.0.1:8789)。
2. 登录时选择「管理员」，输入刚才设置的管理密码。
3. 打开「登录管理」，设置一个独立的录分密码。
4. 将共享计分台地址和录分密码交给录分员。录分员填姓名和录分密码。管理员可查看最近登录和当前在线会话。姓名由录分员填写，在线状态以最近 60 秒内与主机通信为准。
5. 在「登录管理」可暂停或恢复所有录分，也可停用在线录分员的姓名，再从「已停用的姓名」恢复。暂停会终止对应会话。录分员共用密码并自行填写姓名，需要彻底停止访问时可暂停全部录分或更换录分密码。

### 让其他电脑连入

GitHub 仓库存放源码。其他电脑需要能访问同一台计分主机上的服务，可在主机上使用自己已有的 HTTPS 反向代理或 HTTPS 私有隧道。代理只接受共享域名，把请求转发到 `http://127.0.0.1:8789`，将转发的 `Host` 固定为共享域名，并保留浏览器发送的 `Origin`。以下域名仅为占位符，替换为自己的地址：

```bash
python3 server.py serve --data-dir "$HOME/choir129-data" --port 8789 --origin https://scoring.example.org
```

把实际 HTTPS 地址给录分员。管理员在主机 Chrome 中访问 `http://127.0.0.1:8789` 登录，共享 HTTPS 地址只接受录分员登录。主机和转发服务在比赛期间需保持运行。启动该方式前，先退出使用同一数据目录的桌面计分台。每个数据目录仅运行一个服务实例。

## 录分与冲突

- 每个格子对应一个院系、一位评委和一项数据。总分按回车或离开输入框保存，特色奖选择后保存。
- 不同格子可同时录入。同一格同时提交相同值时，两边均成功。若两人基于同一旧值提交不同内容，主机保留先保存的值，后提交者收到弹窗并看到主机值。核对后可以重新输入。
- 管理员可设置参赛单位和评委、查看排名、全屏展示奖项、导出和恢复备份。录分员可录分和投票。
- 专家、教师、学生的权重为 75%、15%、10%。教师组、学生组在至少 3 份有效分时各去掉一高一低。特色奖按各组得票率加权，先给未获等级奖的院系分配，名额为 5、4、5。

## 备份与恢复

分数和票数每次提交后更新数据目录中的 `合唱比赛计分-自动备份.json`。管理员可在「成绩与奖项」导出 CSV，在「参赛与评委」生成手动备份或恢复既有 JSON。旧版自动备份仍可读取。登录记录写入同目录的 `合唱比赛登录记录.json`，管理密码和录分密码的加盐摘要存放在 `.choir-auth.json`。备份和登录记录只由比赛主机保存，避免将数据目录提交到 GitHub。

## macOS 桌面版

需要 Xcode Command Line Tools、Python 3 和 Google Chrome：

```bash
bash build-mac.sh
python3 server.py set-admin --data-dir "$HOME/Desktop/大三-主席团/06_129合唱比赛"
python3 server.py set-staff --data-dir "$HOME/Desktop/大三-主席团/06_129合唱比赛"
```

双击 `build/合唱比赛计分台.app`，应用会用 Chrome 直接打开本机管理员界面。桌面版沿用 `桌面/大三-主席团/06_129合唱比赛` 里的自动备份。要让其他电脑连接，按上面的 HTTPS 步骤启动共享地址。
