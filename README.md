# 一二·九合唱比赛计分台

北京化工大学一二·九合唱比赛的录分和特色奖投票工具。Mac 和 Windows 都可用浏览器登录录分。

## 登录并开始录分

1. 向比赛负责人领取**录分链接**和**录分密码**。如果领取的是局域网链接，请先把电脑连到比赛指定的同一网络。
2. 在 **Mac** 或 **Windows** 上打开你常用的现代浏览器，例如 Safari、Edge、Firefox 或 Chrome。把录分链接完整粘贴到地址栏，按回车。
3. 在「合唱比赛计分台」登录页输入**自己的姓名**和**录分密码**，点击「登录」。如果页面提供身份选项，选择「录分员」。录分员只能填写分数和特色奖投票。
4. 进入「现场录分」后，先选参赛单位，再选专家、教师或学生评委组。找到对应评委，在「总分」填写 0 至 100 分，按回车或点到其他位置保存。在同一行「特色奖投票」的下拉框中选一项，选择后自动保存。
5. 确认页面显示「已保存到计分主机」。录分结束后，点击右上角「退出登录」。

GitHub 页面可以查看源码和这份说明。现场录分请使用比赛负责人发给你的录分链接。录分时无需 GitHub 账号，也无需下载安装计分台。

## 管理员登录

1. 在 Mac 或 Windows 的浏览器打开比赛负责人给出的同一条计分台链接。使用局域网链接时，先连接比赛指定网络。
2. 在登录页选择「管理员」，输入管理密码，点击「登录」。
3. 进入后，可在「参赛与评委」维护名单和出场顺序，在「成绩与奖项」核对结果。计分主机上的「登录管理」可查看在线情况、暂停其他设备登录，并结束其当前会话。

## 多人同时录分

- 不同院系、评委或项目可以同时填写。
- 两人对同一格提交相同分数时，两边均可保存。
- 两人对同一格提交不同分数时，系统保留先保存的分数，后提交者会收到弹窗并看到已保存的分数。核对后再重新录入。

## 打不开或无法登录

- **打不开页面**：检查是否粘贴了完整的录分链接。使用局域网链接时，请确认电脑接入比赛指定网络，再向负责人核对当前链接。
- **提示密码错误或录分权限暂停**：核对姓名和录分密码，或联系比赛负责人确认当前状态。
- **提示登录已过期**：回到登录页，重新输入姓名和录分密码。
