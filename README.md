# 一二·九合唱比赛计分台

## 直接打开登录页

**先连接与计分主机相同的北京化工大学校园网 Wi‑Fi，再打开下面的链接。** 如果看到多个校园网名称，请向比赛负责人确认当前使用的 Wi‑Fi 名称。

**[点击打开计分台登录页](http://10.4.115.203:8789/)**

如果点击后没有打开，请完整复制下面的地址，粘贴到浏览器顶部的地址栏，再按回车：

```text
http://10.4.115.203:8789/
```

这是**当前比赛局域网的登录地址**。请在相同的校园网 Wi‑Fi 上使用，并确认计分服务已开启。若比赛负责人发了新地址，以负责人发的地址为准。

## Mac 和 Windows 怎么打开

| 电脑 | 操作 |
| --- | --- |
| **Mac** | 打开 Safari、Chrome、Firefox 等现代浏览器。按 `⌘ + L` 选中地址栏，粘贴完整地址，按 `Return`。 |
| **Windows** | 打开 Edge、Chrome、Firefox 等现代浏览器。按 `Ctrl + L` 选中地址栏，粘贴完整地址，按 `Enter`。 |

打开后，页面标题应为「合唱比赛计分台」，表单第一项为「登录身份」。两种身份都从这个页面进入。录分无需安装软件或登录 GitHub。

## 登录身份怎么选

| 身份 | 需要填写 | 登录后的入口 |
| --- | --- | --- |
| **录分员** | 自己的姓名、比赛负责人发给你的录分密码 | 现场录分和特色奖投票 |
| **管理员** | 比赛负责人发给你的管理密码 | 参赛与评委、成绩与奖项、获奖展示等 |

### 录分员登录

1. 点开「登录身份」，选择「录分员」。
2. 在「姓名」栏填写自己的姓名，便于负责人核对登录记录及录分冲突。
3. 在「密码」栏输入录分密码，点击「登录」。
4. 登录成功后进入「现场录分」，页面顶部会显示你的姓名。

### 管理员登录

1. 打开上方同一个登录链接，在「登录身份」中选择「管理员」。
2. 输入管理密码并点击「登录」。选择管理员后，姓名栏会隐藏。
3. 登录后按需进入「参赛与评委」或「成绩与奖项」。

## 登录后怎么录分

1. 在「现场录分」左侧选择本轮要录的**参赛单位**，再核对录分区顶部的院系名称。
2. 在录分区选择**专家、教师或学生**评委组，找到要录入的评委。
3. 在该评委行的「总分」栏输入 **0 至 100** 分。按回车或离开输入框后提交。
4. 如需录入该评委的特色奖票，在同一行「特色奖投票」中选择一项，选择后自动保存。
5. 看到页面顶部显示「已保存到计分主机」后，再继续录下一位评委或下一支队伍。已保存的分数会同步到其他已登录页面。
6. 录分结束后，点击右上角「退出登录」。

录分员可以填写分数和特色奖票。参赛名单、出场顺序和评委设置由管理员维护。

## 多人同时录分遇到冲突怎么办

- 不同院系、评委或项目可以同时填写。正在输入的格子会保留本次输入，提交时再核对。
- 同一格提交相同分数，两边均可保存。
- 同一格提交不同分数，系统保留已保存的值。两位相关录分员和管理员会收到提示，提示里有院系、评委和两个分数。请核对原始评分，由管理员更正。

## 链接打不开或无法登录

| 现象 | 怎么处理 |
| --- | --- |
| 打开后仍在 GitHub 文件页 | 点击本页顶部的「点击打开计分台登录页」，或把登录地址复制到浏览器地址栏。 |
| 浏览器提示无法连接、连接超时 | 确认电脑和计分主机连接的是同一个北化校园网 Wi‑Fi，核对地址是否完整保留了 `http://` 和端口 `8789`。仍打不开时，请向负责人确认计分服务是否正在运行、地址是否已变。 |
| 显示登录页，但提示密码错误 | 核对「登录身份」是否选对，再核对该身份对应的密码。录分员还要填写姓名。 |
| 提示权限已暂停 | 联系比赛负责人确认录分权限和登录状态。 |
| 登录过期或页面返回登录页 | 重新打开同一个链接，选择身份并再次登录。 |
| 填了分数，但没看到保存成功 | 按回车提交，检查分数是否在 0 至 100 之间。若出现冲突提示，按提示核对，等管理员处理。 |
